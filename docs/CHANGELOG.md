# 变更记录

## 2026-09-15｜说明号改版、PRD 外挂说明与演示工具

- **字段说明号**由悬浮 ⓘ 改为红框序号：每个页面从 1 开始独立编号，表格下方给出对应的口径说明清单，不再依赖鼠标悬停；同时去掉造成鼠标变问号的 `cursor:help`。
- **返利数据底表**菜单修正为仅超级管理员可见（此前样式覆盖了隐藏属性，导致其他角色也能看到）。
- **导入示例数据**从 `app.js` 移至 `mock-data.js` 的 `importSamples`，作为数据维护。
- 新增 **PRD 说明抽屉**，顶部「PRD 说明」按钮打开，右侧滑出，含五个页签：
  - 流转与时间轴：合同状态流转图、预警邮件推送时间轴，并标注与现有代码不一致处；
  - 补充说明：系统间同步、返利变更追溯、数据迁移、币种、并发等无界面内容；
  - 版本变化：按版本列出条目，用颜色区分新增、修改、删除，并标注提出人与已开发／待开发状态；
  - 演示工具：模拟返利变更、挑款金额变化、合同金额变小、合同终止四种外部数据变动，触发后真实释放关联并弹出释放通知邮件预览；
  - 相关链接：方案文档、测试用例等飞书链接，维护在 `mock-data.js` 的 `prd.links`。
- 合同终止后从待关联与已关联列表中移除，明细页同步过滤。
- 项目改为 git 仓库管理，历史提交随包附带。

## 2026-09-15｜演示模式、权限、模板与导入落地

- 顶部新增**演示模式**开关，默认开启。开启时显示角色切换与字段口径说明号；关闭后这些辅助元素全部隐藏，页面即为上线形态，便于截图与交付。
- 顶部新增**角色切换**（仅查看、可编辑、采购经理、超级管理员），切换后按钮、行操作与菜单实时变化：仅查看隐藏导出模板与批量导入、行操作只剩查看详情；采购经理在已关联列表才有解锁入口；返利数据底表菜单仅超级管理员可见。
- **字段口径说明号**：在列表与详情的表头字段旁增加 ⓘ，鼠标悬停显示方案中的口径定义，覆盖合同剩余返利金额、剩余可关联金额、挑款金额、关联类型、关联金额、是否有效等 14 个字段。
- **导出待关联模板**由提示改为模板字段预览：首行说明加 8 个字段的必填标记与填写说明。
- **批量导入**改为真实执行：内置三份示例数据（全部合规、逐行校验失败、合并校验失败），按方案口径真实跑逐行校验与合并校验，逐行不通过时不再执行合并校验；全部通过则真实写入数据，列表、返利底表余额与合同流转结果同步更新。
- **分页**接通：支持每页 10/20/50 条、翻页、页码省略与跳转，查询与重置回到第 1 页。
- 演示数据扩充至 23 个合同行、17 条关联记录、7 条挑款关系，覆盖多事业部、多产品线、多币种与一合同多核算大类的场景。

## 2026-09-15｜UI 校准与筛选可用化

- 侧栏只保留预计返利管理模块，删除其余业务菜单；一级菜单右侧箭头恢复为收起与展开标记，点击可折叠子菜单，图标随状态在 ⌃ 与 ⌄ 之间切换。
- 详情页与编辑页改回线上的宽表形态：合同公共列回到表格内并支持横向滚动，取消上一版的合同信息卡；编辑态保留「合同剩余返利金额」列并随输入实时更新。
- 四个列表页的筛选条件改为真实筛选，作用于派生后的数据集：文本项模糊匹配，下拉项按现有数据动态生成选项，日期项按区间过滤，合同出库金额按大于 0 与等于 0 过滤。查询、重置、回车均生效，导出按当前筛选结果计数。
- 编辑页删除已保存的关联返利行时，按方案改为立即失效并释放金额。
- 编辑页序号前的「已保存」标签取消，第一列统一为复选框并在表头提供全选；已保存行仍可勾选删除，其只读状态由返利编码与本次关联金额不可编辑体现。
- 返利选择弹框按线上 UI 重排：筛选区第一行为返利编码与返利名称，第二行为剩余可关联金额区间、按产品线查询与查询按钮；表格首列增加全选；底部补分页器并显示已选条数。

## 2026-09-15｜按方案 V1.2 与前后端代码重构原型

### 文档

- `refs/backend.md`：新增后端事实摘录，覆盖核心表、字段、口径、保存链路、导入链路、同步与释放。
- `docs/00-facts.md`：按后端代码补齐核心口径、保存校验、自动释放、预警与权限事实；删除历史遗留的 `关联收款` 分支与「相同合同仅支持一种关联类型」的表述。
- `docs/01-prd.md`：改为与方案 V1.2 一致，补充数据粒度、批量导入、预警邮件；原三条待确认已在评审中定论，予以移除。
- `docs/02-states.md`：补齐编辑态与解锁态的全部边界场景。

### 原型

- 数据层：`mock-data.js` 成为唯一数据源，改为合同行加关联记录的结构；合同剩余返利金额、关联类型、已关联金额、剩余可关联金额一律由 `app.js` 实时派生，不再写死。
- 金额运算改为按分取整，修复小数相减的浮点误差。
- 待关联列表补齐核算大类、合同剩余返利金额、币种、预计返利时间、关联类型；到款金额为 0 时不展示「关联到款」。
- 已关联列表移除自造的「已关联金额」「部分关联状态」，字段与代码对齐。
- 已关联返利明细补齐币种、事业部、产品线、核算大类、合同出库金额、到款ID、挑款金额、关联金额。
- 详情与编辑由弹窗改为整页视图，合同公共信息上移为信息卡，表格只保留关联相关列。
- 编辑页新增表头关联方式切换、返利选择弹框（含按产品线查询与多选）、增加一行、删除所选。
- 编辑页实现六项保存校验，含跨合同行的挑款额度合并校验与两种关联方式的合同额度合并校验。
- 关联到款行按挑款记录自动带出，填 0 表示取消关联。
- 新增已关联详情的有效 / 失效筛选与整页解锁视图（逐条勾选、原因必填）。
- 批量导入补充模板说明与整批失败的逐行错误列表。
- 修复原型既有问题：已关联列表查看详情取错列导致合同号显示为事业部；重置按钮漏清下拉筛选；选择返利按数组下标定位导致多选写错行。

### 原因

将原型口径与方案 V1.2 及前后端实际实现对齐，使评审看到的界面即为上线后的形态。
