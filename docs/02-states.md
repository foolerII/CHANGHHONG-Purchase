# 状态与边界情况

## 页面状态

| 场景 | 预期表现 |
|---|---|
| 初始进入 | 展示默认分页与查询条件 |
| 无查询结果 | 表格显示空状态，分页保留 |
| 查询中 | 查询与导出按钮 loading，避免重复提交 |
| 导入中 | 全屏上传遮罩并禁止重复点击 |
| 导入失败 | 弹框逐行列出错误，不做部分导入 |
| 导入成功 | 提示成功并刷新待关联列表 |
| 只读记录 | 仅显示查看详情 |
| 可读写记录 | 显示查看详情与编辑 |
| 非采购经理查看已关联 | 不显示编辑（解锁）入口 |

## 编辑态边界

| 场景 | 处理 |
|---|---|
| 关联返利行未选返利编码 | 阻止保存，提示第 N 行请先选择返利信息 |
| 本次关联金额为空、为负或超过两位小数 | 阻止保存并提示 |
| 候选返利剩余可关联金额为 0 | 不出现在返利选择弹框中 |
| 同一返利编码新增多行 | 允许，按合计校验剩余可关联金额 |
| 已保存的关联返利行 | 金额不可修改，不参与剩余额度校验 |
| 删除已保存的行 | 二次确认后立即失效并释放金额，不依赖保存按钮 |
| 删除未保存的行 | 仅从页面移除 |
| 同一合同行下到款ID重复 | 阻止保存并提示到款ID重复 |
| 同一到款ID在本合同多个合同行合计超挑款金额 | 阻止保存并提示合计金额与挑款金额 |
| 关联返利与关联到款合计超预计返利金额 | 阻止保存 |
| 关联到款金额填 0 | 视为取消该笔关联，原记录失效且不新增 |
| 切换关联方式 | 仅切换表格列，已填内容保留，两种方式在同一次保存中提交 |
| 保存后剩余金额大于 0 | 提示剩余金额，合同仍停留在待关联 |
| 保存后剩余金额等于 0 | 提示已移入已关联返利合同 |
| 该合同在到款系统无挑款记录 | 关联到款表格显示「该合同在到款系统中暂无挑款记录」 |

## 解锁态边界

| 场景 | 处理 |
|---|---|
| 一条都未选择解锁 | 阻止保存并提示至少选择一条 |
| 选择解锁但未填原因 | 阻止保存并提示解锁原因必填 |
| 解锁关联到款且挑款金额不为 0 | 原记录失效，新增一条关联金额为 0 的待关联记录 |
| 解锁成功 | 释放金额，合同回到待关联，发送释放通知邮件 |

## 数据边界

- 所有金额按分做整数运算后再展示，保留两位小数，不得出现浮点误差。
- 合同剩余返利金额在编辑页实时显示，含未保存输入；列表页与流转判断以已保存数据为准。
- 详情页的有效 / 失效筛选默认有效，清空后展示全部。
- 日期范围支持为空，仅在有值时组装开始与结束字段。
- 长字段列使用省略展示并提供悬浮提示。
- 接口与权限失败提示由项目全局错误处理统一实现。
